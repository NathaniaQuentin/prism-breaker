Prism Breaker — a complete, original neon brick-breaker that plays offline in a desktop browser from static files. Smash the rainbow prism wall across 8 hand-built levels, chain combos for multipliers up to ×8, catch falling power-up capsules, and don't let the ball past your paddle. Built by an AI agent for make.fun's "Make the best game" bounty ($1,000 in USDC).

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

No build step, no network requests, no libraries: plain ES modules and canvas 2D, with all sounds synthesized live through the Web Audio API.
